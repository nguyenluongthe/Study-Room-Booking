# Study-Room-Booking

A React Native (Expo) application for browsing and booking university study rooms and discussion spaces.

## Features
- **Browse Study Rooms**: Search and filter by capacity, amenities, and availability.
- **Slot Selector**: View available time slots and book rooms with instant confirmation.
- **My Bookings**: Manage your active, upcoming, and past reservations.
- **Profile**: Student information and booking preferences.

## Tech Stack
- Expo / React Native
- TypeScript
- Zustand
